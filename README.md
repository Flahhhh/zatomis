<h1>Zatomis</h1>
Zatomis - микро фреймворк для lora-mesh сетей, работающий по принципу клиент-сервера. Данный репозиторий содержит пример приложения в основной директории, а также сам фреймворк в директории zatomis. 

<h2>Установка и запуск:</h2>
git clone flahhh/zatomis
cd zatomis

python -m venv venv
venv/Scripts/activate - Windows
sudo source venv/bin/activate - Linux

pip install -r requirements.txt
python app.py
